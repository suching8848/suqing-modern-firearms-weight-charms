# 蘇清的现代枪械减重挂件

面向《Project Zomboid》[ModernFirearmsSystem（现代枪械系统）](https://steamcommunity.com/sharedfiles/filedetails/?id=3633421539)的个人减重附加模组。

> **制作缘由很简单：我想同时带一把步枪和一把大狙，但是太重了，所以给自己做了两件减重挂件。**
>
> **这会极其影响枪械的真实性与负重平衡，纯粹是个人便利需求。追求真实负重、原模组平衡或硬核生存体验的玩家，请慎用。**

![蘇清的现代枪械减重挂件宣传图](docs/assets/cover.png)

宣传图为 AI 生成的氛围插画。图中的人物、服装与武器展示不会作为人物皮肤或模型安装进游戏；本模组不添加枪上可见的挂件模型。

## 两种挂件

| 挂件 | 适用条件 | 最大减重 | 独立物品自重 |
| --- | --- | --- | --- |
| 蘇清的现代枪械减重挂件（轻型） | 符合判定的枪械 | 1.5 | 0.1 |
| 蘇清的现代枪械减重挂件（重型） | 裸枪脚本基础重量严格大于 5.0 | 5.0 | 0.2 |

以上数值都是游戏内的重量数值。重型资格按裸枪脚本基础重量判断，基础重量恰好为 5.0 不符合；不能通过加装重配件来获得资格。

- 轻型和重型每把枪只能安装一个。
- 挂件占用 `Misc` 杂项槽，与同槽配件互斥，可以和普通枪械背带共存。
- 它不占人物穿戴的 Noir 枪带或人物背枪位置。
- 在其他配件修正计入后，挂件最多按上表减重，并把其参与计算的枪体与附件重量保留在至少 0.1。
- 弹药和弹匣内容不参与挂件可减重量，仍正常计入负重。轻枪可能达不到完整的 1.5 减重。
- 手持、背挂负重继续使用游戏原生系数；其他模组改变计重时，以实际游戏结果为准。

例如：裸枪基础重量 7.0、没有弹药及其他附件时，重型挂件会把参与计算的枪体重量降到 2.0。这个幅度很大，正是它会明显破坏真实性与平衡性的原因。

## 安装

1. 订阅并启用[原模组 ModernFirearmsSystem](https://steamcommunity.com/sharedfiles/filedetails/?id=3633421539)。
2. 退出游戏，备份存档和已有的同名本地模组目录。
3. 将仓库内 `mods/PetGunWeightKits_4221_Local` 整个文件夹复制到 Windows 用户的 `Zomboid/mods` 目录下。
4. 确认最终结构为：

   ```text
   Zomboid/
   └─ mods/
      └─ PetGunWeightKits_4221_Local/
         └─ 42/
            ├─ mod.info
            └─ media/
   ```

5. 启动游戏，在模组列表和目标单人存档中启用“蘇清的现代枪械减重挂件”，并让它在 `ModernFirearmsSystem` 之后加载。

不要把整个仓库根目录放进 `Zomboid/mods`；需要复制的是上述模组文件夹。已经使用旧版“宠物减重套件”的玩家沿用原 Mod ID，无需额外启用第二份相同 ID 的模组。

## 获得与使用

### 制作

打开制作菜单，在“武器”分类搜索“蘇清”或“减重挂件”。配方默认可见。

| 挂件 | 机械等级 | 消耗材料 | 保留工具 |
| --- | --- | --- | --- |
| 轻型 | 1 | 铝材 ×2、螺丝 ×2、胶带 ×1 用量 | 螺丝刀 |
| 重型 | 3 | 铝材 ×4、螺丝 ×4、胶带 ×2 用量 | 螺丝刀 |

这里的铝材是 `Base.Aluminum`（Aluminum Foil，铝箔）；不同汉化名称可能有差别。“铝废料”和“铝碎片”不能替代。

### 自然掉落

| 容器分布 | 轻型相对权重 | 重型相对权重 |
| --- | --- | --- |
| 枪店配件柜 `GunStoreAccessories` | 1.0 | — |
| 警局武器柜 `PoliceStorageGuns` | 0.5 | — |
| 军事武器柜 `ArmyStorageGuns` | 0.8 | 0.15 |

这些是原生抽取的相对权重，**不是掉落百分比**。实际结果还受物资稀有度及同一容器内其他物品影响。模组不会给已经填充的旧箱子补发挂件，也没有新增定时刷新或僵尸掉落；可以前往尚未探索、未填充容器的地区寻找。

### 安装与拆卸

将挂件放入人物主背包，确保枪械 `Misc` 槽空闲，再使用右键“安装配件”，或在 MFS 枪械检视界面的杂项槽安装。安装不额外要求工具。

拆卸可使用原生配件菜单，或按 MFS 当前界面的操作方式移除对应槽配件。挂件可以重复使用；两种挂件不能叠加。

## 存档与停用

旧版 `Sling` 槽挂件保留了原物品定义与 ID：普通容器中的旧散装挂件可自动迁移为新版；枪上的旧挂件在 `Misc` 空闲时迁移。若杂项槽已占用，会保留原位继续生效，腾空后再迁移。

原生存档不会保存配件实例的动态减重修正，本模组会在读档、装卸、装备、转移及容器检查时恢复修正。

**停用或删除模组之前，请先从所有枪上拆下本模组挂件，并处理已有的挂件物品，再备份存档。** 保留 Mod ID 和物品 ID 是为了兼容旧存档，不建议自行重命名这些内部标识。
